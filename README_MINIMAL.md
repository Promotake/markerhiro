Минимальная версия ЛР4.
Что изменено:
- робот стоит прямо на маркере HIRO;
- убрана лишняя панель и сложная верстка;
- камера должна занимать весь экран.

Как применить:
1. Замените в репозитории файлы index.html и hiro_preset.html.
2. Загрузите папку assets/js/simple-ar.js.
3. При желании замените preview.html.
4. Остальные файлы можно не трогать, если папка assets/models уже есть.
