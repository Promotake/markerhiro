# ЛР4 — исправление чёрных полос на iPhone

## Причина
AR.js формирует изображение камеры и отдельную WebGL-сцену. В прошлом
варианте они были выровнены, но занимали только среднюю часть экрана.
Сверху и снизу оставался чёрный фон: камера отображалась в режиме «вписать».

## Что исправлено
- Видео камеры и 3D-сцена увеличиваются **одинаковым преобразованием**
  (режим cover), без растягивания по вертикали.
- Лишние области обрезаются по краям. Это нормально для вертикального экрана.
- Робот остаётся привязан к квадратному маркеру через `square_marker.patt`.
- Остаётся только камера и робот: надписей, кнопок и панелей нет.
- Модель, маркер и положение робота не изменялись.

## Обновление GitHub Pages
1. Откройте репозиторий https://github.com/promotake/markerhiro
2. В корне замените `index.html` новым файлом.
3. При желании замените `hiro_preset.html` (содержит ту же AR-сцену).
4. Сохраните Commit changes.
5. Откройте: https://promotake.github.io/markerhiro/?v=cover8
6. Покажите телефону тот же квадратный маркер без букв HIRO.

Не удаляйте `marker/square_marker.patt` и
`assets/models/astrabot.glb`: на них ссылается страница.

Важно: исправление проверено по коду и в синтетическом мобильном макете,
но фактическую работу с камерой Safari необходимо проверить на iPhone.
