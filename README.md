# Лабораторная работа №4 — AR.js / A-Frame

## Что исправлено

- Белая полоса справа: в портретном режиме AR.js меняет ширину и отступы `body`.
  Теперь основная страница закреплена на весь экран, а сцена WebGL получает
  точные размеры и координаты видеопотока AR.js, без дополнительного искажения.
- Смещение 3D относительно маркера: видеослой и GL-canvas выровнены как единая
  4:3-проекция, одинаково обрезаемая экраном телефона.
- Робот увеличен с 0.55 до 0.85 (примерно на 55%). Его геометрический центр
  совмещён с центром маркера. Непрерывное вращение отключено.
- В основной странице нет кнопок и надписей.

## Обновление сайта

1. Откройте GitHub-репозиторий `promotake/markerhiro`.
2. Замените только `index.html` в корне. Также можно заменить `hiro_preset.html`.
3. Нажмите `Commit changes` и дождитесь окончания GitHub Pages deployment.
4. Откройте на iPhone `https://promotake.github.io/markerhiro/?v=center7`.
5. На компьютере покажите `marker/square_marker.png` (новый квадратный маркер, не HIRO).

Важно: в GitHub должны оставаться исходные файлы
`assets/models/astrabot.glb` и `marker/square_marker.patt`.

## Примечание о 3D

Точка крепления робота стоит на геометрическом центре маркера. При косом угле
съёмки верхушка высокой модели может выглядеть смещённой из-за перспективы.
Это нормально для настоящего трёхмерного объекта: главное, чтобы точка опоры
не меняла положение относительно маркера.

Работа на реальной камере iPhone требует проверки после публикации.
