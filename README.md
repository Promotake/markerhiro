# Лабораторная работа № 4 — маркер без текста

Это готовая AR-страница на AR.js и A-Frame. В браузере отображается камера, а при обнаружении **нового квадратного маркера** в его центре появляется AstroBot. Надписей и кнопок на странице нет.

## Что поменялось

- Стандартный HIRO **больше не используется**. Обычный `preset="hiro"` не распознаёт новый рисунок.
- Создан собственный рисунок `marker/square_marker.png` без букв.
- `marker/square_marker.patt` — шаблон распознавания этого рисунка; `index.html` ссылается именно на него через `<a-marker type="pattern" url="...">`.
- По центру рисунка есть чёрный квадрат с небольшим белым квадратиком в углу внутри него, чтобы поворот маркера различался и робот не разворачивался на 90° случайным образом.
- Для печати подготовлен `marker/square_marker_A4.pdf`.

## Установка на GitHub Pages

1. Откройте репозиторий `https://github.com/promotake/markerhiro`.
2. Замените `index.html` и `hiro_preset.html` файлами из этого архива.
3. Добавьте **оба новых файла**: `marker/square_marker.png` и `marker/square_marker.patt` (и по желанию PDF для печати). Сохраните папку `marker`.
4. Старые `hiro.png` и `.patt` можно оставить в репозитории, но **не используйте их** для новой страницы.
5. После публикации откройте `https://promotake.github.io/markerhiro/?v=square3` на телефоне.
6. На мониторе откройте `https://promotake.github.io/markerhiro/marker/square_marker.png` или распечатайте PDF. Наведите камеру на **новый**, а не HIRO-маркер.

**Важно:** хотя `hiro_preset.html` оставлен для совместимости со старой ссылкой, он тоже работает с новым квадратным маркером.

## Почему маленький белый уголок нужен

Идеально симметричный рисунок из вложенных квадратов практически одинаков при повороте на 90°. Из-за этого отслеживание ориентации неустойчиво. Небольшая асимметрия в рисунке улучшает определение поворота при минимальном отличии от простого квадрата. При необходимости можно придумать другую асимметричную фигуру без надписей.

Возможности телефона и конкретного браузера удалённо не проверены. Если трекинг будет нестабилен, увеличьте новый маркер на мониторе, улучшите контраст и исключите блики.
